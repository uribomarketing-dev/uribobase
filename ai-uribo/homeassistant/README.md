# Home Assistant 連携（玉里のAIハブ 4C）

**目的**：カメラのAIが書く文章に頼らず、**Frigateの検知（事実）**をAI Uriboへ自動で流す。

分かっている環境（2026-08-12時点）

| 何が | どこに |
|---|---|
| **Home Assistant** | `http://192.168.1.13:8123`（バージョン 2025.5.3／最新は2026.8.1） |
| **OpenClaw** | `http://192.168.1.13:18789`（セットアップURL：`:11435`） |
| **Frigate** | 同じハブに同居（設定画面あり） |
| カメラ | Pan/Tilt Cam Plus 3K FB（玉里キッチン）。「人を検出」は **ON に変更済み** |

**全部が1台（AIハブ 4C・192.168.1.13）の中**で動いています。
どれも**玉里のLANからしか開けません**（外出先からはTailscale等が必要）。

> ⚠ 清水のNASも `192.168.1.20` と、**同じ 192.168.1.x 帯**です。
> Tailscaleで両拠点をつなぐ場合、サブネットが衝突して片方に届かなくなることがあります。
> 将来つなぐときは、どちらかの拠点のLANを別の帯（例：192.168.10.x）に変える必要が出るかもしれません。

## OpenClaw と Home Assistant の役割分担

| | 使いどころ |
|---|---|
| **Home Assistant**（本命） | Frigateの検知＝**事実**をAI Uriboへ自動送信。文章の質に左右されない |
| **OpenClaw** | 人向けの会話・提案。「今日の玉里の様子は？」と聞く用途。**記録の材料としては二番手** |

OpenClawの画面（`:18789`）に入れたら、**Skill／ツール／HTTP** といった項目があるか見てください。
あれば、そこからもAI Uriboへ送れます（こちらで定義を書きます）。
ただし**まずはHome Assistantの方**を動かすことをおすすめします。確実で、壊れにくいためです。

## 手順（30分ほど）

### 1. Home Assistantの画面に入る

**玉里のWi-Fiにつながった端末**から `http://192.168.1.13:8123` を開きます。
（外出先からは開けません。Tailscaleを通すか、現地で作業してください）

### 2. AI UriboのURLを登録する

HAの `config/secrets.yaml` に1行足します（ファイルエディタのアドオン、またはSSHで編集）。

```yaml
ai_uribo_url: "https://script.google.com/macros/s/＜デプロイID＞/exec?k=＜WEBHOOK_SECRET＞"
```

> このURLは**AI Uriboのデプロイ後に確定**します。まだ無い場合は、先に
> `docs/デプロイ手順.md` の手順4まで進めてください。

### 3. 連携ファイルを置く

`ai_uribo.yaml` を HAの `config/packages/ai_uribo.yaml` に置きます。
packagesを使っていなければ、`configuration.yaml` に次を足してから再読み込み：

```yaml
homeassistant:
  packages: !include_dir_named packages
```

### 4. entity_id を実際の名前に直す

`★要変更` と書いた3か所です。**開発者ツール → 状態** で、`binary_sensor.` と打つと
候補が出ます。Frigateの人物センサーは `binary_sensor.<カメラ名>_person` という名前が多いです。

### 5. 設定を再読み込みして、テスト送信

- 設定 → システム → 再起動 →「YAML設定の再読み込み」
- 開発者ツール → サービス → `rest_command.ai_uribo_observe` → YAMLモードで：

```yaml
data:
  target: "ALL"
  item: "食事提供"
  value: "テスト送信"
```

台帳の **S4_実績ログ取込** に `raw_home-assistant` の行が増えれば成功です。
LINEで `精査` と送っても確認できます。

## よくある疑問

**Q. AI Uriboが家のネットワークに入ってくるの？**
いいえ。**Home Assistantから外へ送るだけ**の一方通行です。ルーターの穴あけ（ポート開放）は不要で、
外から家のカメラに触れる経路も作りません。

**Q. 何度も送られたら記録が増えない？**
増えません。AI Uribo側で「同じ日・同じ対象・同じ項目」は1件しか記録しない作りです。
送信回数を絞る調整に時間をかけなくて大丈夫です。

**Q. HAのバージョンが古い（2025.5.3 → 2026.8.1）。先に更新すべき？**
**連携だけなら更新は不要**です。`rest_command` も自動化も2025.5.3で動きます。
更新中はカメラの見守りが止まり、microSDや電源の扱いにも注意が要ります。
**先に連携を動かして、落ち着いてから、時間に余裕のある日に更新**するのをおすすめします。
（更新するなら、その前にHAのバックアップを取ってください）

**Q. 玉里だけ？清水は？**
清水にAIハブが無ければ、清水はセンサー（開閉・人感）とLINEの質問で埋めます。
玉里で効果が確認できたら、清水にもAIハブを置く判断材料になります。

## 送る内容を増やすとき

`ai_uribo.yaml` の automation を1つコピーして、`item` を変えるだけです。
`item` に使える名前は、台帳の **S3_チェック項目マスタの「項目名」**と同じ文字列にしてください
（食事提供／在否確認／夜間の動き／外出・帰宅時間／入浴／日中活動 など）。
項目名が一致すると、**その項目はLINEで質問されなくなります**。
