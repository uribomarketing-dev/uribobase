# AIハブ側の設定（貼り付けるだけ）

方針は `docs/AIハブ活用方針.md`。ここはその**実装**です。
考えるところは全部こちらで書いてあります。**現地の作業は貼り付け3回**です。

---

## これで何が起きるか

```
Frigate（ローカル・無料）が共用部で人を検出
  → Home Assistant が「時刻つきの事実」だけをAI Uriboへ送る（画像は送らない）
    → 翌朝の「夜間巡回・就寝確認」の質問に
       （参考）夜間の動き：共用部で動きあり 00:15／02:40／04:30
       が付いて届く
      → 夜勤の方は思い出さずに、事実を見て1タップで答える
```

**誰の記録にするかは決めません。**共用部のカメラは「誰が」までは分からないので、
AI Uriboに入るのは拠点共通の事実だけです。記録として確定させるのは人です。

---

## 手順（3回貼るだけ・15分）

### 事前：AI Uriboのウェブアプリを先にデプロイしておく

送り先URLが無いと何も始まりません。`docs/デプロイ手順.md` の手順で
`https://script.google.com/macros/s/＜デプロイID＞/exec` を発行し、
メニュー「③ ウェブアプリURLを登録する」まで済ませてください。

### 1. secrets.yaml に送り先を書く

Home Assistant → 設定 → アドオン → **File editor**（無ければ Studio Code Server）で
`/config/secrets.yaml` を開き、末尾に1行足します。

```yaml
ai_uribo_url: "https://script.google.com/macros/s/＜デプロイID＞/exec?k=＜WEBHOOK_SECRET＞"
```

`＜WEBHOOK_SECRET＞` は、スプレッドシートのメニュー「① 秘密情報を入力する」で
表示された24文字です。**このURLは秘密情報**として扱ってください（外に貼らない）。

### 2. configuration.yaml に3行足す（すでにあれば不要）

```yaml
homeassistant:
  packages: !include_dir_named packages
```

### 3. ai_uribo.yaml を置く

`/config/packages/ai_uribo.yaml` として、このフォルダの
[`homeassistant/ai_uribo.yaml`](homeassistant/ai_uribo.yaml) をそのまま保存。

そのあと **開発者ツール → YAML → 「すべての YAML 設定を再読み込み」**。

---

## 動いているかの確かめ方

1. **開発者ツール → アクション**（旧サービス）で `rest_command.ai_uribo_observe` を選び、
   次を実行する

   ```yaml
   date: "2026-08-13"
   target: "ALL"
   item: "夜間の動き"
   value: "テスト送信"
   ```

2. スプレッドシートの **S4_実績ログ取込** に `取込元=frigate` の行が増えていれば成功
3. 増えていなければ `secrets.yaml` のURL（特に `?k=` の値）を確認

## 前提と注意

- **MQTTは要りません。**2026-08-13の実機確認で、玉里のHome Assistantには
  MQTTもFrigate統合も入っていないと分かりました。一方で
  `http://192.168.1.13:5000/api/version` は `0.16.0-c2f8de9` を返す＝**FrigateのAPIは生きている**。
  そこで**FrigateのAPIを5分ごとに読む方式**にしてあります。統合を足す必要はありません。
  将来MQTTを入れれば、ファイル末尾の案内どおり差し替えると即時になります
- **検出から記録まで最大5分の遅れがあります。**記録される時刻は
  Frigateが検出した時刻（`start_time`）なので、**記録の時刻はずれません**
- **連投は夜30分に1件にまとめています。**人が1度通るだけでFrigateは何件もイベントを出すためです。
  夜の記録として意味があるのは「何時ごろ動きがあったか」なので、これで十分です
- **深夜0〜5時の検知は「前の晩」として記録します。**夜勤は日付をまたぐためです
  （AI Uribo本体のSwitchBot取り込みと同じ扱いにしてあります）
- **送る `item` は、AI Uribo側の項目名をそのまま使います。**（例：`夜間の動き`）
  共用部のカメラは「誰が」までは分からないので、**利用者個人の記録には変換しません**。
  S4に事実として残り、質問の「（参考）」として使われるだけです
- **③のAI+シーン検知はコメントアウトしてあります。**
  AI+の検知がHome Assistantに届くかは未確認のためです。届くと分かってから外します
