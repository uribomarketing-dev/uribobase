> **貼ったら、まずここを確認してください（10秒）。**

1. 台帳のタブに戻って**再読み込み**（メニューに「AI Uribo」が出ます）

## 4. ウェブアプリとして公開し、LINEにつなぐ（5分）

1. Apps Scriptの画面右上 **デプロイ →「新しいデプロイ」**
2. 歯車 → **ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（LINEサーバーから届かせるために必要）
3. デプロイ → 表示された **URL（/exec で終わる）をコピー**
4. 台帳のメニュー **「③ ウェブアプリURLを登録する」** に貼り付け
   → **LINEに貼るWebhook URLがそのまま表示されます**
5. LINE Developers → Messaging API設定 → **Webhook URL** にそれを貼る
   → 「**検証**」を押して成功を確認 → **Webhookの利用：オン**
6. LINE Official Account Manager → 応答設定 → **応答メッセージ：オフ／Webhook：オン**

## 7. 玉里のAIハブとつなぐ（10分・2026-08-13の現地確認ぶん）

> **貼る前に1回：** `cd ai-uribo && bash tools/check_all.sh`
> 本体のテスト・ハブ側の設定の検査・貼り付け用ファイルの作り直しを、まとめて実行します。
> 「すべてOK。貼って大丈夫です」と出たら進んでください。


**ここまで（1〜6）が終わっていれば、ハブ側は貼るだけです。**
現地で必要なことは 2026-08-13 に全部終わっています。

玉里の実機で確認できていること：

- Home Assistant … **セットアップ済み**（`http://192.168.1.13:8123`）
- Frigate … **稼働中**（`0.16.0-c2f8de9`）。**人の検出が実際に出ている**
- カメラ … 玉里キッチン1台（`B0E9FE038DFB`）。食卓・椅子・食器も認識できている
- ハブの時計 … 正確（記録の日付がずれない）

手順は **`hub/README.md`** にあります。やることは3つだけです。

1. `/config/secrets.yaml` に、6でデプロイしたURLを1行書く
2. `configuration.yaml` に3行足す（すでにあれば不要）
3. `hub/homeassistant/ai_uribo.yaml` を `/config/packages/` に置いて、YAMLを再読み込み

つなぐと、こうなります。

```
夜、共用部で人を検知（Frigate・無料・ローカル）
  → 翌朝の質問に「（参考）夜間の動き：0:15／2:40／4:30」が付いて届く
    → 夜勤の方は思い出さずに、事実を見て1タップで答える
```

**MQTTもAI+も要りません。**（AI+を入れると「配膳している様子」まで拾えるようになりますが、
それは1か月の無料期間で試してから判断すれば十分です）

## つまずいたら

| 症状 | どうするか |
|---|---|
| メニュー「AI Uribo」が出ない | 台帳のタブを再読み込み。それでも出なければ貼り付けが保存されていない |
| 「◯◯ is not defined」 | 貼り付けが途中で切れています。全文をコピーし直してください |
| Webhookの「検証」が失敗 | URLの末尾に `?k=…` が付いているか。デプロイのアクセス範囲が「全員」か |
| 何が悪いか分からない | メニュー「通し試験を実行」→ 出た画面をそのまま私に渡してください |
