## 1. コードを貼る（3分）

1. 上の台帳を開く → メニュー **拡張機能 → Apps Script**
2. 出てきた `コード.gs` の中身を**すべて消す**
3. 下のファイルを開き、**全文をコピー**して貼り付け、保存（Ctrl+S / ⌘S）

   https://github.com/uribomarketing-dev/uribobase/blob/claude/ai-uribo-system-build-eaa1fq/ai-uribo/dist/AI_Uribo_%E5%85%A8%E9%83%A8%E5%85%A5%E3%82%8A.gs

   > GitHubの画面右上にコピーボタン（四角が重なったアイコン）があります。それを押すのが確実です。

4. 左の歯車（プロジェクトの設定）→「`appsscript.json` マニフェスト ファイルをエディタで表示する」にチェック
5. 現れた `appsscript.json` の中身を、下の内容で置き換えて保存

   https://github.com/uribomarketing-dev/uribobase/blob/claude/ai-uribo-system-build-eaa1fq/ai-uribo/src/appsscript.json

## 2. LINEのトークンを入れる（2分）

1. 台帳のタブに戻って**再読み込み**（メニューに「AI Uribo」が出ます）
2. メニュー **「AI Uribo」→「① 秘密情報を入力する（LINEトークン）」**
3. LINE Developers →「うりぼシフト管理」チャネル → **Messaging API設定 → チャネルアクセストークン（長期）** を貼り付け
4. 次の画面（チャネルシークレット）は**空欄のままOK**で構いません

> Webhook用の秘密キーは**自動で作ります**。最後に出る `?k=…` 付きのURLは、
> このあと使うのでコピーしておいてください（あとからでも確認できます）。

## 3. 台帳を組み立てる（1分）

メニュー **「AI Uribo」→「② はじめの設定（quickStart）」**

13シートができ、スタッフ4名・チェック項目17件・設定35件が入ります。
**テストモードがONになる**ので、この時点では現場にLINEは飛びません。

## 4. ウェブアプリとして公開し、LINEにつなぐ（5分）

1. Apps Scriptの画面右上 **デプロイ →「新しいデプロイ」**
2. 歯車 → **ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（LINEサーバーから届かせるために必要）
3. デプロイ → 表示された **URL（/exec で終わる）をコピー**
4. 台帳のメニュー **「③ ウェブアプリURLを登録する」** に貼り付け
   → **LINEに貼るWebhook URLがそのまま表示されます**
5. LINE Developers → Messaging API設定 → **Webhook URL** にそれを貼る
   → 「**検証**」を押して成功を確認 → **Webhookの利用：オン**
6. LINE Official Account Manager → 応答設定 → **応答メッセージ：オフ／Webhook：オン**

×があれば、その行に「どう直すか」が書いてあります。

## つまずいたら

| 症状 | どうするか |
|---|---|
| メニュー「AI Uribo」が出ない | 台帳のタブを再読み込み。それでも出なければ貼り付けが保存されていない |
| 「◯◯ is not defined」 | 貼り付けが途中で切れています。全文をコピーし直してください |
| Webhookの「検証」が失敗 | URLの末尾に `?k=…` が付いているか。デプロイのアクセス範囲が「全員」か |
| 何が悪いか分からない | メニュー「通し試験を実行」→ 出た画面をそのまま私に渡してください |
