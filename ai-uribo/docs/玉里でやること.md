# 玉里でしかできないこと（現地作業リスト）

AIハブ（`192.168.1.13`）は**玉里のLANからしか触れません**。
ここに挙げたものは、離れた場所からは代われない作業です。逆に言うと、
**ここに無いものは全部あとでできます**（Apps Scriptの貼り付け・LINE設定・シフト表の取り込みなど）。

**iPhone1台あれば全部できます。**（Macがある場合は最後の「おまけ」の方が速いです）

まず **iPhoneのWi-Fiが玉里のものにつながっているか**だけ確かめてください。
4G/5Gのままだとハブには一切つながりません。

## ① SwitchBotアプリでカメラの画角を見る（5分）★今日いちばん価値がある

（玉里キッチン＝**Pan/Tilt Cam Plus 3K FB**。モデル名は2026-08-13に確認済みです）

OpenClawが書ける記録は「**映っているもの**」が上限で、これは現物を見ないと分かりません。
キッチンのカメラの映像を出して、**見えるものに○、見えないものに×**を付けてください。

| 見たいもの | ○/× | これが見えると埋まる項目 |
|---|---|---|
| 食卓に料理が並ぶところ（配膳） | | 食事提供 |
| 誰かが食事している様子 | | 食事提供・日中の様子 |
| 服薬ボックスのあたり | | 服薬確認（声かけの材料） |
| 玄関・出入り | | 在否確認・外出/帰宅 |
| 暗い時間に人が動くのが分かるか | | 夜間巡回・就寝確認 |

夜の見え方も一言だけ：**真っ暗で何も分からない／人影は分かる／顔まで分かる**。
「人影は分かる」程度でも**夜間の在室**は埋められます。

**映像そのものは送らないでください。**○×と一言で十分です（利用者が映るため）。

## ② RTSPを有効にする（5分）★2026-08-13に対応を確認しました

玉里キッチンは **Pan/Tilt Cam Plus 3K FB**、**RTSP対応**（実機確認済み）。
これを有効にすると、**ハブの中（Frigate／OpenClaw）で映像を直接読める**ようになります。
＝ AIまとめを人が貼り付けなくても、記録の材料が自動で入ってくる道が開きます。

アプリ → カメラの設定 → **サードパーティーサービス** → Home Assistant連携 → アカウント編集

- ユーザー名：`Admin` のままで可（変えられるなら変える）
- パスワード：**ランダムな16文字以上**。**SwitchBotアカウントとは別のもの**にする
  （公式の注意書きどおり。アプリの自動生成があればそれで結構です）
- 保存したら、**パスワードは1Passwordなどへ**。メモアプリやチャットには置かない

控えていただきたいのは**カメラのIPアドレスだけ**です（`192.168.1.xx`）。
**パスワードとRTSPのURLは送らないでください。**こちらは「有効にした」と分かれば設計できます。

⚠ ルーターで**外向きにポートを開けないでください**（玉里のLANの中だけで使います）。

## ②b プリセットポイントを登録する（5分）★現地でしかできない

首振りカメラなので、**見る場所を時間帯で変えられます**。
アプリ → **プリセットポイント設定**で、カメラを動かして次の3つを登録してください。

| 名前 | 向ける先 | 使いどき |
|---|---|---|
| `食卓` | 配膳・食事が見える向き | 朝・昼・夕の食事提供 |
| `服薬` | 服薬ボックスのあたり | 服薬の声かけの材料 |
| `玄関` | 出入りが見える向き | 在否・外出/帰宅 |

映る範囲が居室に入らないように向けてください（共用部だけにするのが原則です）。
登録した**名前だけ**教えていただければ、時間帯ごとの切り替えはこちらで組みます。

## ③ ついでに：アプリの機器一覧（1分）

一覧に**清水の開閉センサーと玉里の機器が両方出ているか**。

- 両方出ている → アカウント1つ。APIトークン1本で両拠点ぶん読めます
- 出ていない → 拠点ごとに別アカウント。どちらを使うか決める必要があります

## ④ Safariで Home Assistant を開く（2分）

アドレスバーに **`http://192.168.1.13:8123`** と入力（`https` ではありません）。

- **開いた** → そのままスクショを1枚。左メニューの項目名（Frigateが居るか等）が分かれば十分です
- **開かない** → 「ハブがネットワークにつながっていない」という**大きな発見**です。
  そう教えてください（ハブの電源とLANケーブルだけ見てもらえると助かります）

## ⑤ つながっている機器の一覧をコピーする（5分・できれば）

一覧が取れると、**どのセンサーをどの記録に使えるか**をこちらで全部設計できます。

1. 左下の**自分の名前**をタップ → 「**詳細モード**」をON
2. 左メニューに出てくる「**開発者ツール**」→ 上のタブ「**テンプレート**」
3. 左側の枠の中身を全部消して、下の3行を貼り付け

```
{% for s in states if s.domain in ['camera','binary_sensor','person','device_tracker'] %}{{ s.entity_id }} | {{ s.name }} | {{ s.state }}
{% endfor %}
sensor{{ states.sensor | list | count }}件 / 全{{ states | list | count }}件
```

4. 右側に出た結果を**長押し→全選択→コピー**して、そのまま送ってください

（うまくいかなければ飛ばして結構です。④のスクショだけでも進められます）

## ⑥ OpenClawが動いているかを確かめる（5分）

**ブラウザで `http://192.168.1.13:18789` を直接開いても繋がりません。**
セキュリティのため既定で遮断されていて、**SwitchBotアプリでOpenClawのページを一度開くと、
そこから10分間だけ**ブラウザでも開けるようになります（公式仕様）。

なので、アプリから確かめるのが確実です。

1. アプリ → **AIハブ** → 設定 → **OpenClaw設定**（無ければ、ファーム V3.1以上／アプリ V9.24以上か確認）
2. 未設定なら「**ワンクリック設定**」（15〜20分かかります。**ハブと同じWi-Fiにいること**／SDカードが必要）
3. 設定済みなら、チャットに `hello` → 返事があればOK
4. 続けてチャットに
   `SwitchBotアカウントに登録されているデバイスを一覧表示してください`
   → 返ってきた一覧をそのまま送ってください。
   **清水の開閉センサーも出るか**で、アカウントが1つか2つかも同時に分かります（③の代わりになります）

## ⑦ ネットワークを控える（1分）

iPhoneの **設定 → Wi-Fi → 接続中のネットワークの (i)** をスクショ。
IPアドレスとルーターのアドレスが写っていればOKです。
（清水NASと同じ `192.168.1.x` 帯なので、将来Tailscaleでつなぐときに衝突します。今日直す必要はありません）
