# 玉里でしかできないこと（現地作業リスト）

AIハブ（`192.168.1.13`）は**玉里のLANからしか触れません**。
ここに挙げたものは、離れた場所からは代われない作業です。逆に言うと、
**ここに無いものは全部あとでできます**（Apps Scriptの貼り付け・LINE設定・シフト表の取り込みなど）。

**iPhone1台あれば全部できます。**（Macがある場合は最後の「おまけ」の方が速いです）

まず **iPhoneのWi-Fiが玉里のものにつながっているか**だけ確かめてください。
4G/5Gのままだとハブには一切つながりません。

---

## ① SwitchBotアプリでカメラの画角を見る（5分）★今日いちばん価値がある

OpenClawが書ける記録は「**映っているもの**」が上限で、これは現物を見ないと分かりません。
キッチンのカメラの映像を出して、**見えるものに○、見えないものに×**を付けてください。

| 見たいもの | ○/× | これが見えると埋まる項目 |
|---|---|---|
| 食卓に料理が並ぶところ（配膳） | | 食事提供 |
| 誰かが食事している様子 | | 食事提供・日中の様子 |
| 服薬ボックスのあたり | | 服薬確認（声かけの材料） |
| 玄関・出入り | | 在否確認・外出/帰宅 |
| 暗い時間に人が動くのが分かるか | | 夜間巡回・就寝確認 |

夜の見え方も一言だけ：**真っ暗で何も分からない／人影は分かる／顔まで分かる**。
「人影は分かる」程度でも**夜間の在室**は埋められます。

**映像そのものは送らないでください。**○×と一言で十分です（利用者が映るため）。

## ② カメラのモデル名を控える（2分）

SwitchBotアプリ → 機器を選ぶ → 設定（歯車）→ **機器情報**。スクショで結構です。

- 玉里 1台目（キッチン）：__________
- 玉里 2台目：__________
- もう1拠点の1台：__________

**3MP Plus / Pan-Tilt なら RTSP（映像の直接取り込み）が使える見込み**で、精度が上がります。
無印3MPだと難しくなります。

## ③ ついでに：アプリの機器一覧（1分）

一覧に**清水の開閉センサーと玉里の機器が両方出ているか**。

- 両方出ている → アカウント1つ。APIトークン1本で両拠点ぶん読めます
- 出ていない → 拠点ごとに別アカウント。どちらを使うか決める必要があります

## ④ Safariで Home Assistant を開く（2分）

アドレスバーに **`http://192.168.1.13:8123`** と入力（`https` ではありません）。

- **開いた** → そのままスクショを1枚。左メニューの項目名（Frigateが居るか等）が分かれば十分です
- **開かない** → 「ハブがネットワークにつながっていない」という**大きな発見**です。
  そう教えてください（ハブの電源とLANケーブルだけ見てもらえると助かります）

## ⑤ つながっている機器の一覧をコピーする（5分・できれば）

一覧が取れると、**どのセンサーをどの記録に使えるか**をこちらで全部設計できます。

1. 左下の**自分の名前**をタップ → 「**詳細モード**」をON
2. 左メニューに出てくる「**開発者ツール**」→ 上のタブ「**テンプレート**」
3. 左側の枠の中身を全部消して、下の3行を貼り付け

```
{% for s in states if s.domain in ['camera','binary_sensor','person','device_tracker'] %}{{ s.entity_id }} | {{ s.name }} | {{ s.state }}
{% endfor %}
sensor{{ states.sensor | list | count }}件 / 全{{ states | list | count }}件
```

4. 右側に出た結果を**長押し→全選択→コピー**して、そのまま送ってください

（うまくいかなければ飛ばして結構です。④のスクショだけでも進められます）

## ⑥ OpenClawの画面を開く（1分）

アドレスバーに **`http://192.168.1.13:18789`**（開かなければ **`:11435`** も）。
**出てきた画面をスクショ1枚**。どの版でどこまでできるかが分かると、
「AI Uriboへ観察を送る」設定をこちらで書けます。

## ⑦ ネットワークを控える（1分）

iPhoneの **設定 → Wi-Fi → 接続中のネットワークの (i)** をスクショ。
IPアドレスとルーターのアドレスが写っていればOKです。
（清水NASと同じ `192.168.1.x` 帯なので、将来Tailscaleでつなぐときに衝突します。今日直す必要はありません）
