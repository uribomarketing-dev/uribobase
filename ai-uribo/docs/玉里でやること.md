# 玉里でしかできないこと（現地作業リスト）

AIハブ（`192.168.1.13`）は**玉里のLANからしか触れません**。
ここに挙げたものは、離れた場所からは代われない作業です。逆に言うと、
**ここに無いものは全部あとでできます**（Apps Scriptの貼り付け・LINE設定・シフト表の取り込みなど）。

所要時間の目安：**スクリプト2分＋目視10分**。

---

## 0. 先にやっておくと、今日で一巡します（玉里でなくてもよい）

AIハブから記録を送るには、送り先のURL（ウェブアプリURL）が要ります。
**先にApps Scriptの貼り付けとデプロイを済ませておくと、玉里でつなぎ込みまで終わります。**
まだなら `docs/いますぐの手順.md` の①〜③（15分）を先に。

済んでいなくても、下の1〜5は無駄になりません（調べるだけなので）。

---

## 1. 【自動】ハブの中身を丸ごと調べる（2分）

Macを**玉里のWi-Fi**につないで、ターミナルで：

```sh
sh ~/Desktop/tamari_hub_check.sh
```

デスクトップに `tamari-hub-YYYYMMDD-HHMM.txt` ができるので、**そのまま送ってください**。
読み取るだけで、ハブの設定は一切変えません。

Home Assistantの中身（カメラ名・センサー名の一覧）まで取るなら、先に **2** のトークンを作って：

```sh
HA_TOKEN='作ったトークン' sh ~/Desktop/tamari_hub_check.sh
```

> トークンは結果ファイルには書き出されません。**トークン自体はチャットにも貼らないでください。**
> 使うときは、Apps Scriptの「スクリプトプロパティ」に入れます（メニュー①と同じ扱い）。

---

## 2. 【人】Home Assistantの長期アクセストークンを作る（3分）

**LANの中からしか作れません。** これがあると、AI Uriboがハブのセンサーを読めるようになります。

1. `http://192.168.1.13:8123` を開く
2. 左下の**自分の名前** → 一番下「**長期アクセストークン**」
3. 「トークンを作成」→ 名前は `AI_Uribo`
4. 表示された文字列を**その場でコピー**（二度と表示されません）
5. メモアプリではなく、パスワード管理（1Password等）か、Apps Scriptのプロパティへ

---

## 3. 【人】キッチンのカメラに何が映っているかを見る（5分）

ここが**今日いちばん価値のある作業**です。
OpenClawが書ける記録は「映っているもの」が上限で、それは現物を見ないと分かりません。

カメラの映像を出して、**見えるものに○、見えないものに×**を付けてください。

| 見たいもの | 見える？ | AI Uriboの項目 |
|---|---|---|
| 食卓に料理が並ぶところ（配膳） | | 食事提供 |
| 誰かが食事している様子 | | 食事提供・日中の様子 |
| 服薬ボックスのあたり | | 服薬確認（声かけの材料） |
| 玄関・出入り | | 在否確認・外出/帰宅 |
| 夜間（暗い時間）に人が動くのが分かるか | | 夜間巡回・就寝確認 |

あわせて：**夜、赤外線でどのくらい見えるか**（真っ暗で何も分からない／人影は分かる／顔まで分かる）。
「人影は分かる」程度でも、**夜間の在室**は埋められます。

---

## 4. 【人】カメラのモデル名を控える（2分）

本体の裏ラベル、またはSwitchBotアプリ →機器 →設定 →機器情報。

- 玉里 1台目（キッチン）：モデル名 ______
- 玉里 2台目：モデル名 ______
- もう1拠点の1台：モデル名 ______

**3MP Plus / Pan-Tilt なら RTSP（映像の直接取り込み）が使える可能性**があり、
FrigateやOpenClawの精度が上がります。無印3MPだと難しくなります。

---

## 5. 【人】ネットワークを控える（3分）

- ルーターの管理画面（たいてい `192.168.1.1`）にログインできるか：できる／できない
- **ハブのIPが固定されているか**（DHCP予約があるか）。
  固定でないと、停電のあとに `192.168.1.13` が変わって連携が黙って止まります
- ルーターの**LAN側アドレス帯を変えられるか**（清水NASと同じ `192.168.1.x` で、
  将来Tailscaleで両拠点をつなぐときに衝突します。今日直す必要はありません）

---

## 6. 【ついでに】SwitchBotアプリの確認（2分・どこでもできる）

アプリの機器一覧に、**清水の開閉センサーと玉里の機器が両方出ているか**。

- 出ている → アカウントは1つ。APIトークン1本で両拠点ぶん読めます
- 出ていない → 拠点ごとに別アカウント。どちらのトークンを使うか決める必要があります

## 持ち帰っていただくもの（この4つで足ります）

1. `tamari-hub-*.txt`（スクリプトの結果）
2. 3の表（○×と、夜の見え方）
3. 4のモデル名
4. 5の3点（ルーターに入れるか／IP固定か／帯を変えられるか）

これがあれば、**OpenClawからAI Uriboへ観察を流し込む設定**と、
**HAのセンサーを自動充足に使う設定**を、こちらで書いて渡せます。
