# 玉里でやること（2026-08-13 改訂）

方針は `docs/AIハブ活用方針.md` に一本化しました。この文書はその**現地作業ぶんだけ**です。
順番どおりにやれば詰まりません。**全部で30分**。

**持ち物：microSDカード 128GB以上（高耐久／監視カメラ用・2〜3千円）**
ついでにLANケーブル（数m）があれば尚よし。

現地に着いたら、まず **iPhoneのWi-Fiを玉里のもの（`pr500k-d091b4-…`）に切り替え**てください。
4Gのままだとハブに一切つながりません。

---

## ① microSDを差し替える（5分）※急ぎではありません

**SDが要るのはOpenClawと録画の余裕だけです。**そのOpenClawは脇役に降格したので、
**カードが無くても④⑤③はすべてできます。**買えた日にやれば十分です。

いまのカードは**14.5GBで空き1.26GB**。OpenClawはSD必須、HAもSDを使うので、
この状態では設定が失敗します。

1. アプリ → AIハブ → **ローカルストレージ**で、いまの使用量をもう一度確認
2. ハブの電源を抜く → microSDを差し替える → 電源を入れる
3. アプリでカードが認識されたら、**その画面からフォーマット**（新品なので消えて困るものはありません）
4. **古いカードは捨てずに持ち帰って保管**（過去のイベント録画が入っています）

**時間が無い日は、④と⑤（合わせて8分・見るだけ）だけで結構です。**
この2つで「追加費用ゼロの夜勤巡回記録が作れるか」が決まります。

## ② AI+サービスを開始する（3分）

**初月無料**です。これが無いと「配膳した」「横になった」を言葉にできません（月約700円）。

アプリ → AIハブ（またはカメラ）→ AI関連のプラン案内から加入。
**開始日をメモ**してください（1か月後に継続を判断します）。

## ③ シーンを1つだけ作る（10分）★今日の本題

**いきなり全部作らないでください。1つで十分です。**精度が分かってから増やします。

カメラの **動体検出 → 発動条件（カスタマイズ）** に、自然文でこう書きます。

```
食卓に料理が並んでいる
```

- 通知先は**自分（藤原様）だけ**にしてください。現場に流すのは精度が分かってからです
- 作ったら、**今晩の夕食で実際に通知が飛ぶか**を見ます。これが今日いちばんの成果になります
- 飛んだ／飛ばなかった、を明日教えてください。それで設計が確定します

## ④ カメラの画角を見る（5分）★まだ聞けていません

映像を出して、**見えるものに○、見えないものに×**。

| 見たいもの | ○/× |
|---|---|
| 食卓に料理が並ぶところ（配膳） | |
| 誰かが食事している様子 | |
| 服薬ボックスのあたり | |
| 玄関・出入り | |
| 暗い時間に人が動くのが分かるか | |

夜の見え方も一言：**真っ暗／人影は分かる／顔まで分かる**。
**映像そのものは送らないでください。**○×で十分です。

## ⑤ Frigateを開く（3分）★アプリから開けます

アプリ → AIハブ → **設定 → Frigate設定 → URLをタップ**（公式手順。`:8123`の手打ちは不要）。

見るのは2つだけです。

1. **キッチンのカメラが一覧に出ているか**（出ていれば映像の取り込みはもう出来ています）
2. 左メニュー **「Events」に人の検出が時刻付きで溜まっているか** → **スクショを1枚**

ここが埋まっていれば、方針の1位「**夜勤の巡回記録**」が**追加費用ゼロ・ローカル処理**で今日から作れます。

⚠ Eventsのサムネイルに利用者が写る場合は、**時刻の列だけ分かれば十分**です。
写り込む部分は隠して送ってください。

（Frigateが開かない／カメラが出ない場合は、それも大きな発見です。そう教えてください）

- **プリセットポイント3つ**（`食卓` / `服薬` / `玄関`）。居室が映り込まない向きで。名前だけ教えてください

  つないだらIPが変わることがあるので、アプリで新しいIPを確認してください
