# カメラ運用の整理（たたき台）

作成：2026-08-13

**これは法律の助言ではありません。**管理者・サービス管理責任者にご確認のうえ、
必要なら市の担当課や顧問に見ていただく前提の**たたき台**です。
そのまま使える形にはしてありますが、**最終判断は事業所側でお願いします**。

---

## 1. いま玉里で起きていること（事実の整理）

| 項目 | 状態 |
|---|---|
| 設置場所 | **共用部（台所・食堂）のみ**。居室には設置していない |
| カメラ | Pan/Tilt Cam Plus 3K FB（1台）＋玄関に別カメラ |
| 録画 | **イベント録画のみ**（動きがあったときだけ）。常時録画ではない |
| 保存先① | AIハブのmicroSD（施設内） |
| 保存先② | **SwitchBotのクラウドに最大30日**（AIガードプラン プレミアム） |
| AI解析 | 映像から「何が起きたか」を**言葉にする**（AI+／AIガードプレミアム） |
| AI Uriboへ渡すもの | **言葉と時刻だけ。画像・映像は一切渡さない**（設計で固定） |

**押さえておくべき点：映像は施設内だけでなく、事業者のクラウドにも保管されています。**
これは「AI Uriboは映像を扱わない」とは別の話で、**カメラを設置している事業所としての説明責任**です。

---

## 2. なぜ整理が要るか

障害者グループホームの共用部にカメラがある状態は、それ自体が禁じられるものではありません。
問題になるのは**「利用者・家族が知らないうちに撮られている」**ことと、
**「誰がいつまで見られるのか決まっていない」**ことです。

実地指導で問われるとしたら、カメラの有無ではなく次の3点です。

1. **目的**が説明されているか（防犯なのか、支援の質の確認なのか）
2. **範囲と期間**が決まっているか（どこを撮り、何日残し、誰が見るのか）
3. **本人・家族に説明し、掲示しているか**

---

## 3. 決めておくルール（案）

| 項目 | 決め（案） |
|---|---|
| 設置場所 | **共用部のみ。居室・浴室・トイレには設置しない**（例外なし） |
| 目的 | ①緊急時の把握と安全確保 ②支援記録の正確性の確保 ③防犯 |
| 録画方式 | イベント録画のみ（常時録画はしない） |
| 保存期間 | 施設内SD：容量の範囲／クラウド：**30日で自動消去** |
| 閲覧できる人 | **管理者・サービス管理責任者・代表のみ**。夜勤者は閲覧しない |
| 閲覧する場面 | 事故・ヒヤリハット・苦情の確認時に限る。**日常的な勤務確認には使わない** |
| 記録への扱い | 映像は記録そのものにしない。**AIが言葉にしたものは「推定・要精査」**として扱い、確定は人が行う |
| 音声 | 録音機能がある場合は**オフ**にする（会話の録音は説明の負担が大きく増える） |
| 職員への説明 | 職員も撮影対象になることを事前に説明する（**勤務評価には使わない**と明示する） |

> **「日常的な勤務確認には使わない」は必ず入れてください。**
> ここを曖昧にすると、現場は「監視されている」と受け取ります。
> AI Uriboが記録を助ける仕組みとして受け入れられるかどうかは、ここで決まります。

## 4. 掲示文（案）

共用部の入口など、**利用者と来訪者の目に入る場所**に掲示します。

```
　　　　　　　　カメラ設置のお知らせ

当ホームでは、共用部（台所・食堂・玄関）にカメラを設置しています。

【目的】
　・緊急時に、すぐ状況を把握して対応するため
　・支援の記録を正確に残すため
　・防犯のため

【撮影する場所】
　共用部のみです。居室・浴室・トイレには設置していません。

【録画のしかた】
　動きがあったときだけ短時間記録します。常時録画はしていません。

【保存期間】
　30日を過ぎたものは自動的に消去されます。

【見ることができる人】
　管理者・サービス管理責任者・代表に限ります。
　事故やご相談の確認のときにだけ確認します。
　日々の勤務の確認には使用しません。

　ご質問・ご不安があれば、いつでも職員にお申し出ください。

　　　　　　　　　　　　　　　　合同会社Uribo　うりぼベース玉里
　　　　　　　　　　　　　　　　　　　　　　　　20  年  月  日
```

## 5. 重要事項説明書への追記（案）

契約時・更新時に、次の一項を加えて説明します。

```
（設備・記録について）
　当ホームの共用部（台所・食堂・玄関）には、緊急時の対応、支援記録の
正確性の確保、および防犯を目的としてカメラを設置しています。居室・浴室・
トイレには設置していません。
　記録は動きがあったときのみ短時間保存し、30日を経過したものは自動的に
消去されます。閲覧は管理者・サービス管理責任者・代表に限り、事故・
ヒヤリハット・ご相談の確認のときにのみ行います。
　記録の一部は、支援記録を作成する補助として、映像から文章化した情報
（時刻と出来事の記述）のみを用います。映像そのものを記録として保存・
提出することはありません。
```

---

## 6. 職員向けの一言（朝礼・LINEで一度だけ）

```
共用部のカメラについて、改めてお伝えします。

・カメラは共用部だけです。居室には付けていません
・見るのは、事故やご相談があったときだけです
・日々の勤務ぶりの確認には使いません。ここは約束します
・AIが映像から読み取った内容は「たぶんこうだった」という材料で、
　記録として確定させるのは皆さんです

「夜、何時ごろ動きがありました」という材料をお出しするのは、
思い出して書く負担を減らすためです。監視のためではありません。
```

---

## 7. やること（順番）

1. 上の**ルール（3章）を管理者と決める**（30分）
2. **掲示を貼る**（4章。印刷して1枚）
3. **職員に一度説明する**（6章。朝礼で1回）
4. 次の契約更新・モニタリングのときに**重要事項説明書へ追記**（5章）
5. 音声録音がオンなら**オフにする**

**1〜3は今週中にできます。**4は次の更新時で構いません。

---

## 8. 補足：AI Uribo側で既に守っていること

説明するときに使える材料です。

- 台帳に**利用者の氏名を置いていない**（記号で管理し、LINEの文面を作るときだけ変換）
- 台帳に**画像・映像を一切置かない**（入るのは言葉と時刻だけ）
- **診断名・病名・障害区分は扱わない**
- AIが埋めたものには**「要精査」の印**が付き、人が確認するまで確定しない
- 共用部のカメラからは、**利用者個人の記録を自動で作らない**
  （「誰が」までは分からないため、拠点共通の事実としてのみ残す）
