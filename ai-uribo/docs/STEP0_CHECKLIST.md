## A. Google側の準備

- [ ] **A-1. スプレッドシート作成**
  Googleドライブで新規スプレッドシートを作成し、ファイル名を `AI_Uribo_台帳` にする。
  → **URLをこちらに共有**（`https://docs.google.com/spreadsheets/d/●●●●/edit` の全文）。
  ※中身は空でOK。シートは実装AIの `initSheets()` が自動生成します。

- [ ] **A-2. スプレッドシートのタイムゾーン確認**
  ファイル → 設定 → タイムゾーン＝ `(GMT+09:00) 東京` になっているか確認。
  （バッチ時刻10:00／21:00／3:00がすべてここに従います）

- [ ] **A-3. GASプロジェクトの作成**
  上記スプレッドシートを開き、拡張機能 → Apps Script を開く。
  プロジェクト名を `AI_Uribo` に変更して保存。
  → 表示されるスクリプトIDまたはプロジェクトURLを共有（clasp接続に使用）。
  ※Apps Script側のタイムゾーンも「アジア/東京」になっているか、プロジェクトの設定で確認。

- [ ] **A-4. バックアップ用フォルダ**
  マイドライブ直下に `AI_Uribo_Backup` フォルダを作成（中は空でOK）。
  ※作らなくてもGAS側で自動生成しますが、保存場所を藤原様の意図する場所にしたい場合は先に作ってURLを共有してください。

- [ ] **A-5. 実行アカウントの確認**
  AI Uriboを動かすGoogleアカウント（バッチの実行主体）はどれか。
  → 例：`info@urilabo.com` でよいか／別の運用専用アカウントを使うか。

## B. LINE側の準備

- [ ] **B-1. チャネルアクセストークン（長期）の発行**
  LINE Developers → 「うりぼシフト管理」チャネル（@462oxzee） → Messaging API設定 →
  「チャネルアクセストークン（長期）」を発行し、**文字列を安全な方法で共有**。
  ※このトークンはスクリプトプロパティにのみ保存します。コード・シート・チャットログには残しません。

- [ ] **B-2. チャネルシークレットの控え**
  同チャネルの「チャネル基本設定」→ チャネルシークレットを控える。
  ※Webhookの署名検証（X-Line-Signature）に必須です。

- [ ] **B-3. Webhook設定権限の確認**
  Messaging API設定画面で「Webhook URL」を編集できる状態か確認（Admin権限）。
  URL自体はStep3でこちらが発行してお渡しします。設定後「Webhookの利用」をONにします。

- [ ] **B-4. 応答設定の変更**
  LINE Official Account Manager → 応答設定で
  「応答メッセージ」＝ **オフ**／「Webhook」＝ **オン**／「あいさつメッセージ」＝任意（B-5で差し替え）。
  ※応答メッセージがオンのままだと自動返信とAI Uriboの返信が二重に届きます。

- [ ] **B-5. 表示名・あいさつ文の変更（任意・運用開始前まででOK）**
  アカウント名を「AI Uribo」に変更、あいさつ文を「AI Uriboです。お名前を教えてください」系に差し替え。

- [ ] **B-6. テスト参加者が友だち追加できる状態にする**
  藤原様・服部俊喜様（＋兼崎様）が @462oxzee を友だち追加済みであることを確認。
  ※追加は**Step3のWebhook稼働後**に行ってください（先に追加すると `line_user_id` が自動記録されません。追加済みの場合は一度ブロック→解除で再登録できます）。
