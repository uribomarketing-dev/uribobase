# AI Uribo 使い方マニュアル（1枚）

AI Uribo（LINE）は、記録の抜けを見つけてお尋ねする係です。
**基本は届いた質問のボタンを押すだけ**。1〜2分で終わります。

---

## 1. 届くもの

| いつ | 何が届くか | 誰に |
|---|---|---|
| 毎朝10時 | 昨日の記録で埋まらなかった項目の確認 | 藤原・服部（テスト期間中） |
| 勤務開始の1時間前 | 「夜の確認セット」＝昨日のことと明日の予定 | 夜勤の方 |
| 日曜10時 | 今週の未完了まとめ | 社員 |

機械で分かること（服薬ログ・センサー・ラボ出勤・猪ノ屋日誌の天気や献立、前の晩に聞いた予定）は
**質問しません**。データから推測できることも先に埋めておくので、人にしか分からないことだけが届きます。

先に埋めたもののうち**推測で書いたものには「要精査」の印**が付いています。
社員が `精査` と送ると一覧が出るので、違っていれば台帳で直してください。
AI Uriboは「たたき台を素早く作る係」で、**最終的に正しくするのは現場の皆さんです**。

### 「夜の確認セット」が届く時刻について

**その日の勤務開始の1時間前**に届きます（17時入りの方には16時ごろ）。
シフト表を取り込んでいれば自動でその人に合わせます。
シフト表に開始時刻が入っていない方には、これまでどおり**21時**に届きます。

- いま何時に届く設定になっているかは、メニュー「AI Uribo」→「今日の夜勤を確認する」で見られます
- 何時間前にするかを変えたいときは、S8_設定 の `night_lead_hours` を直してください（既定は1＝1時間前）
- 22時〜7時は送りません。23時入りの方には21時に届きます

---

## 2. はじめの登録（1回だけ）

1. LINEで「うりぼシフト管理（AI Uribo）」を友だち追加します
2. 管理者からお伝えした**登録コード（英数字8文字）**をそのまま送ってください
3. 「○○さんですね。登録しました」と返れば完了です

コードは1回使うと無効になります。分からなくなったら管理者にご連絡ください。
（このコードは、他の人があなたになりすまして記録に答えてしまうのを防ぐためのものです。
人に教えたり、グループに貼ったりしないでください）

## 3. 答え方

1. 届いたメッセージのボタンをタップするだけ
2. 「未実施だった」「わからない」「対応あり」を選んだときだけ、
   **一言だけ**理由を送ってください（例：本人が拒否、外出中）
   - 特に書くことがなければ **「なし」** と送ればOK
3. 1つ答えると次の質問が届きます。全部終わると「これで全部完了です」と出ます

### 答えられないとき

無理をせず **「わからない」** で大丈夫です。社員に引き継がれます。
（「わからない」は記録済みにはならず、日曜のまとめに残ります）

### 夜勤の方へ

夜の確認セットは、**利用者さんと話しながら**答えていただく想定です。
「昨日はお風呂入りましたか？」「明日は出かけますか？」と雑談の中で聞いて、
そのままボタンを押してください。明日の予定を教えていただけると、
**翌日の質問が減ります**（予定どおりなら聞かずに済むため）。

## 4. 自分から送れる言葉

| 送る言葉 | 何が起きるか |
|---|---|
| `状況` | 今の未完了件数と一覧が返ってきます |
| `報告` | 事故・体調急変などをその場で報告できます（次に送った文章が社員に共有されます） |
| `ヘルプ` | 使い方が返ってきます |
| `診断` | （社員のみ）不具合調査用の情報が返ってきます。そのままAIに貼ってください |
| `精査` | （社員のみ）データから推定して埋めた記録のうち、まだ確かめていないものの一覧 |
| `精度` | （社員のみ）自動データがどれくらい当たっているか。もう聞かなくてよくなった項目も分かります |
| `訂正` | 押し間違えたときに、直近3日の回答を選んで直せます（前の回答も履歴に残ります） |
| `夜勤` | 今日の夜勤が誰か（どこから分かったか）が返ってきます |
| `シフト` | （社員のみ）シフト表を貼り付けると、その月は夜勤担当者を毎日聞かれなくなります。**給与ソフトの書き出しをそのまま貼れます** |
| `まとめ` | （社員のみ）SwitchBotアプリの「AIまとめ」を貼り付けると、その日の記録に取り込みます |
| `テスト実行` | （社員のみ）その場で朝バッチを動かします |

ボタン以外の文章を送ると「ボタンでお答えください」と返ります。
故障ではありません。

## 5. よくあること

**Q. 深夜に質問が来ませんか？**
22時〜7時は送りません。その時間に発生した分は朝7時にまとめて届きます。

**Q. 間違えて押してしまった**
`訂正` と送ってください。直近3日にお答えいただいた項目が出るので、選び直せます。
**前の回答も履歴として残ります**（消えるわけではありません）。
3日より前のものは `報告` と送っていただければ社員が直します。

**Q. 同じ質問が2人に届いた**
藤原・服部の2名にまとめて送っています。**どちらか1人が答えれば完了**で、
もう1人にはその項目は届かなくなります。

**Q. 同じ質問がもう一度届いた**
前にお送りして、まだお返事をいただけていない分です。丸1日経つと一度だけお送りし直します
（「前回お答えいただけなかった分も入っています」と書いてあります）。
それでもお答えが無いときは催促せず、日曜のまとめで社員が引き取ります。急かす意図はありません。

**Q. 質問が届かない**
`状況` と送ってみてください。反応がなければ下の連絡先へ。

**Q. 「混み合っています」と返ってきた**
別の処理が動いている時に起きます。1分ほど待ってからもう一度押してください。
（無理に処理を進めて記録が二重になるのを防ぐための動きです）

**Q. センサーが付いているのに、同じことをまた聞かれる**
最初のうちは、センサーからの推定が当たっているかどうかを確かめています。
答えていただいた分だけ実績が貯まり、**十分に当たると分かった項目は質問しなくなります**。
いまどこまで進んでいるかは、社員が `精度` と送ると確認できます。

**Q. 「記録の食い違い」という連絡が来た**
たとえば「外泊していた日に、朝夕とも食事提供の記録がある」のように、
噛み合わない記録が見つかったときに届きます。
AI Uriboは勝手に書き換えません。**どちらが実際だったかを教えてください。**

---

## 6. 困ったときの連絡先

1. まず LINE で `状況` と送って、AI Uribo自体が動いているか確認
2. 反応がない場合：**藤原（代表）** へ連絡
3. 社員は LINE で `診断` と送り、返ってきた文章をAIに貼る（詳しくは `不具合が出たときの伝え方.md`）
4. 社員側の確認手順：
   - スプレッドシート「AI_Uribo_台帳」の **S10_実行ログ** を開き、最新行の「結果」を見る
   - `エラー` があればその「詳細」を藤原へ共有
   - メニュー「AI Uribo」→「セットアップ点検」で設定漏れ（トリガー・トークン）を確認できる

---

## 7. お願い

AI Uriboは**使うほど質問が減る**仕組みです。

- 明日の予定を答えていただくほど、翌日の質問が自動で埋まります
- センサーからの推定は、答えと突き合わせて実績が貯まり、
  **当たると分かった項目は聞かなくなります**（外れが増えたら、また聞きに戻ります）
- 週次のまとめに「自動で埋まった率」「聞かずに済んだ件数」が数字で出ます

最初の数週間だけ少し多く感じるかもしれませんが、だんだん軽くなります。

---

## 8. 社員の方へ：月に一度だけ見ていただきたいもの

毎月1日の朝、**前月の記録の埋まり具合**がLINEに届きます。
拠点ごとの充足率と、記録が足りていない項目が5件まで並びます。

- 実地指導・監査で問われるのは、まさにこの「埋まっていない日」です
- 詳しくは台帳の「月次_YYYY-MM」シートに、利用者×項目ごとの一覧があります
- 「うち推定」は、データから埋めたまま**まだ人が確かめていない**日数です

足りない項目が続いているときは、その項目の聞き方が現場に合っていない可能性があります。
S3_チェック項目マスタの質問文・選択肢はいつでも変えられます（コードの修正は要りません）。
